## 2. 硬件资源

| 外设 | 引脚 | 用途 |
|---|---|---|
| GPIO | PC5 | 心跳 LED |

## 3. 架构（六层 Ports & Adapters）

```
app/        main_loop: 编排（组合根：端口绑定）
domain/     纯逻辑（禁 HAL；host /W4 /WX 编译 = 机械红线）
ports/      纯接口（time/digout/log）
adapters/   接口->硬件绑定（GPIO/HAL）
platform/   寄存器级（rtt_log/log_uart/boot_diag/clock/error）
config/     rtt_events.json（事件表单一事实源）+ app_config.h
```

依赖只向下：app → domain → ports；adapters 实现 ports；platform 是
adapters/驱动层的实现细节。

## 4. RTT 日志系统设计

- 事件表：`App/config/rtt_events.json`（固件头文件由 `asm events-gen` 生成）
- 行格式：`E <seq> <code> <t_ms> <a> <b> <c>\r\n`；a 仅 16 位
- RAM ring 512×16B 死机取证；心跳 #H 活性探针；运行期掩码 J-Link 可写

## 5. 测试策略

- Host：domain 纯逻辑 MSVC /std:c11 /W4 /WX（`asm hosttest`）
- HIL：RTT 事件断言 + witness 符号（`asm hiltest`），四档判定
  PASS/FAIL/KNOWN/SKIP
