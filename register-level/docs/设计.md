## 1. 需求概述

STM32F407VE 全外设教学工程：为《STM32 外设一次讲透》31 集系列
（`VideoPipeline\Project\AutoSTM32`）提供可构建、可上板验证的代码与配置支持。
每个外设一个独立 `bsp_<periph>.c/.h`（寄存器级 + Doxygen 内嵌 CubeMX 配置 +
自测试函数），UART 菜单逐模块验证。

**验收标准**：
1. `asm build`（等价 `cli build`）三判据全过：exit≤1 + `0 Error(s), 0 Warning(s)` + hex 新鲜
2. 每模块有 `bsp_<periph>_selftest()`，注册进 UART 菜单，输出 `PASS/FAIL <name>`
3. 每模块一页 `docs/periph/<name>.md`（CubeMX 等效配置表/引脚表/寄存器表/集数映射）
4. 危险操作（看门狗复位循环/低功耗进入/Flash 擦写）隔离为独立演示命令

## 3. 架构

```
app/        app_main: boot_diag + RTT init + test_menu_run()（组合根）
shell/      test_menu.c 注册表驱动 UART 菜单（selftest 入口 + 演示命令隔离）
bsp/        bsp_<periph>.c/.h 教学模块（寄存器级，全权所有，模块间零 include）
domain/     blink_state（保留：host-tested 域层参考，本工程未接线）
ports/      time/digout/log 纯接口（框架保留）
adapters/   端口->硬件绑定（框架保留）
platform/   rtt_log/log_uart/boot_diag/fault_trampoline/hal_port
config/     rtt_events.json + app_config.h
```

依赖只向下；bsp 层为教学主体（知识 #13：寄存器级模块全权拥有外设，
HAL 初始化在先、bsp 全量重配在后，所有权见各模块文件头注释）。

## 4. regen 后手术清单（每次 `asm cubegen regen` 后逐项核对）

1. `Core/Src/stm32f4xx_it.c`：删除生成的 `HardFault_Handler`（所有者为
   `App/platform/fault_trampoline.s`；先例 ws2812 P001 L6200E）
2. `App/config/app_config.h`：核对心跳三宏（PC5 / 1u<<5u / 32）未被覆盖
3. uvprojx：跑 `cubegen regen --sync-only` 收编 App 组（keilproj LAYERS 已含 bsp/shell）

## 5. 已知边界

- USB CDC / FSMC LCD / I2S 音频 / SDIO 数据通路：文档化扩展位（识别/引脚已就绪，
  协议栈与数据搬运为后续迭代；见 docs/periph/README.md）
- hosttest：本工程无 Tests/host 目录（`asm hosttest` 报 FAILED 为既有缺口，非缺陷）
- RNG 时钟：IOC PLLQ=7 → 48MHz 合规；上板以 CECS 实测为准
